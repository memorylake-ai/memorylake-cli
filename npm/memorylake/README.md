# @memorylake/cli

The [MemoryLake CLI](https://github.com/memorylake-ai/memorylake-cli), packaged
for npm.

```bash
npm install -g @memorylake/cli
memorylake auth login
memorylake version
```

npm downloads only the binary for your machine (macOS, Linux with glibc and
Windows, each on x64 and arm64), from whichever registry or mirror npm is set to
use. Node.js 18 or newer runs the small launcher that starts it.

Upgrade with `npm install -g @memorylake/cli@latest`. Package versions follow
the release tags: `v20261117` is `20261117.0.0`, and a second release the same day,
`v20261117.1`, is `20261117.1.0`.

Commands, configuration and the skills for coding agents are documented in the
[repository README](https://github.com/memorylake-ai/memorylake-cli#readme).
